# Dev-Only Scripts & Tools (QuanNguyenS)

Thư mục này chứa các script phát triển nội bộ, kiểm thử ban đầu và xử lý hình ảnh không nằm trong gói triển khai Production.

- `test-email.js`: Script kiểm thử gửi thử nghiệm Gmail SMTP.
- `test-sheet.js`: Script kiểm thử kết nối Google Sheets Service Account.
- `*.ps1`: Các tiện ích xử lý ảnh SVG/WebP trong quá trình dựng giao diện ban đầu.
